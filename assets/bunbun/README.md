# 🪶 吉祥物：射命丸文（Aya Shameimaru）

**文闻（Bunbun News）** 的吉祥物是 **射命丸文** —— 《东方 Project》里的鸦天狗记者。

## 为什么是她？

| 文文的特点 | 对应本项目 |
|---|---|
| ⚡ 飞行速度是幻想乡第一 | **快** —— 轻量、秒开、后台同步不卡顿 |
| 🪶 经营《文文。新闻》（ぶんぶんまる新聞） | **新闻** —— 我们就是做新闻聚合的 |
| 👁️ 擅长采访、信息灵通 | **准** —— 聚合多源、去重提纯 |
| 📸 招牌动作"捏造照片"（误） | 我们**绝不**捏造 —— 只聚合真实订阅源 |

文文的名字 "Aya" + 报纸名 "Bunbun"，正好是项目名 **Bunbun** 的来历。中文名 **文闻** 取"文"（文文）+ "闻"（新闻）的双关。
